# Arquivos de dados locais

Esta pasta no repositório contém somente a estrutura esperada no USB. Os arquivos comerciais do jogo não são distribuídos aqui.

Na raiz da unidade USB, coloque seus próprios arquivos originais e licenciados em `JediAcademy/data/base/` (por exemplo, os arquivos `assets*.pk3`). Não envie esses arquivos para o GitHub.

Estrutura:

```text
USB:/
├── JediAcademy/
│   └── data/
│       └── base/
│           └── assets*.pk3  # fornecidos pelo usuário
└── HydraOs/
    ├── catalog.json
    └── games/
        └── openjk012.ipk
```
